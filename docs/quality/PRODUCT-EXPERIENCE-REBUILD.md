# 原生产品体验整改（2026-09-07）

本轮依据用户提供的原生窗口截图、同一应用的窗口可访问性状态及 Rust 实现审查。截图中的任务包含实际生成并采用的图片和视频，但默认画面几乎完全用于展示内部运行信息。此前的工程测试通过不能作为产品合格证明。

## 发现与整改

| 问题 | 影响 | 本轮行为 |
| --- | --- | --- |
| 默认任务页堆叠 Mission、Runtime、Worker、权限与版本信息 | 用户看不到已交付的内容，也难以判断下一步 | 先呈现目标、事实状态和当前成果预览；技术信息放入可展开的运行详情 |
| Running 被当作实时执行状态 | 已保存成果的任务仍显示一直在运行 | 结合当前选中任务的执行状态、待确认项和成果状态显示；不把采用等同业务完成 |
| 全部任务以外的筛选是禁用按钮 | 用户无法找到需要处理的任务 | 全部、进行中、待确认、已结束筛选与标题/目标搜索；侧栏待确认进入同一过滤结果 |
| 新失败记录先于当前成果出现 | 已采用素材难找，用户可能检查错版本 | 当前结果优先；打开成果绑定当前生成 ID；历史与失败记录单独展开 |
| 素材只有预览与采用，没有交付到文件的操作 | 用户无法正常拿走生成内容 | 系统保存对话框导出；保存前重新读取解锁上下文并校验类型、长度与摘要 |
| 旧任务没有 Conversation 却显示可编辑输入框 | 输入后发送不可用且缺少可执行的替代路径 | 明确说明旧任务不支持对话，提供可执行的创意工作台入口 |
| 模型入口只有只读运行信息 | 用户无法从错误状态走向配置 | 入口直达模型设置；已有 DeepSeek 本机凭据设置保持原有保存行为 |
| 首次绘制在主线程同步读取系统钥匙串 | 等待系统授权时应用无首屏且窗口工具超时 | 后台读取并展示工作空间打开状态；刷新同样不阻塞界面，仍由系统完成授权 |

## 必须保留的行为

- 待确认的本地写入和工具操作保持在任务页可见，并调用原来的精确批准/拒绝接口；详情折叠不能替代批准。
- 打开媒体预览不自动采用。采用资格仍需当前生成 ID、已解码预览和最新 Mission/WorkProduct/Manifest 版本；失败、历史版本不能被采用。
- 修改描述生成新版本；已采用内容通过“再做一版”保留原成果。恢复视频只查询原任务，不重复 POST。
- 筛选和展示没有新建业务状态。导出是用户选择位置后产生的本地文件，不是发布回执、验证结果或业务成效。

## 验收场景

1. 同一已解锁项目、同一真实素材任务：默认可看到当前图片和视频，运行详情默认折叠；没有活动执行时不得标注“正在处理”。
2. 点击每份成果分别打开工作台，选择必须对应其当前生成 ID；最近失败记录不得抢占打开目标。历史超过 50 条时仍精确取回所选生成记录，缺失时不回退到其他素材。文本成果不触发媒体查找错误。
3. 修改描述后输入获得焦点；取消不生成；生成失败而选中素材未变时，保留原预览资格。采用按钮只有成功解码且当前版本待审阅时可用。超过描述字节限制时明确提示并禁用生成。
4. 导出图片和视频，在系统对话框取消不写文件；确认后文件字节、长度与已选素材摘要相同。项目锁定或字节校验失败时不导出。
5. 搜索匹配、无匹配、清空；切换全部/进行中/待确认/已结束；侧栏待确认和列表状态一致。
6. 工具批准、拒绝、本地写入确认保持可见，并进入待确认计数/筛选；打开其他任务不串用正在执行状态或成果。执行与实时批准来自 command owner 的 Project/Mission 固定身份，legacy 发起时固定身份，页面选择不能改写它。
7. 模型入口可达设置，保存结果由实际运行配置刷新；关闭设置回到原任务。
8. 重开应用仍显示持久成果和采用状态，且不产生新模型调用。有长对话的静态任务首次打开停留于成果；“查看最新消息”主动跳转。旧任务的批准与恢复入口不被素材入口遮挡。

## 当前能力限制

GPT/Grok 文本与图片/视频连接仍主要依赖开发环境；普通用户尚无统一的多提供商设置流程。旧 bootstrap 任务没有通用对话迁移，入口现在明确转向已有的素材工作台。媒体还没有自动调用的 Agent 工具。新任务创建仍要求补全任务范围；尚未实现从一句目标自动提出完整范围并确认后执行的完整产品路径。跨渠道发布、归因和增长效果必须分别验证，不能用生成文件替代。

本轮离线回归、代码审查及真实原生窗口验收分别记录，任一未完成不得用另一项替代。Mac 解锁后，首个修订包的窗口可访问性状态已显示真实图片、视频和成果已保存，但不作为最终视觉验收。最新构建重开时触发系统钥匙串授权；进程采样确认主线程停留于 `DesktopUiModel::load → SecKeychainFindGenericPassword`，因此增加后台读取与等待界面。窗口工具禁止操作系统授权窗口，须由用户完成。最终视觉质量与原生保存对话框在实际操作完成前继续标记为待验收。
