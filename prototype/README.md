# Hartevo Desktop v12 交互原型

`index.html` 是当前冻结交互基线，覆盖项目、Mission、任务、总调度、自然语言入口、连接、渠道、CRM、达人联盟、本地存储、设置、用量、登录与离线状态。

## 打开方式

- 可直接双击 `index.html`。
- 如浏览器限制 `file://` 行为，可用任意本地静态文件服务器打开本目录；这只是原型预览方式，不是 Desktop 的运行时依赖。

## 原型地位

- 原型定义视觉、布局、组件状态和交互细节。
- `docs/product/HARTEVO-DESKTOP-INTERACTION-SPEC.md` 定义行为语义和业务不变量。
- 两者必须同步修改，不保留互相冲突的长期版本。
- 原型不是生产代码，不作为安全、性能或可访问性已经通过的证明。
