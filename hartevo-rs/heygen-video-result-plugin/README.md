# Hartevo HeyGen video-result plugin

This is a standalone Layer-1 workspace for typed HeyGen video-result
proposals and recorded receipts. It exposes a `HeyGenVideoResultService`, a
`HeyGenVideoProvider` over an injected typed HTTPS seam, and a
`MissionVideoResultConsumer`.

Layer 1 does not claim native Connected evidence and does not perform live
generation, upload, avatar or voice cloning, live status polling, webhook
acceptance, media download, media storage, or durable Work Product adoption.
An expiring CDN URL is recorded as ephemeral evidence only. Adoption remains
blocked until a future independent HTTPS byte readback supplies a content
digest and Layer 2 verifies the exact operation, artifact metadata, and
Mission-bound revision.
